Most of my work is on systems that outgrew a single application: services split by domain, talking to each other over gRPC, staying decoupled through asynchronous messaging, and sitting behind a single interface the user never sees the seams in.

I care about boundaries that hold up, code that can be tested without ceremony, and queries that stay fast once the tables are real. I take features from first sketch through to what runs in production.

## What I work on

- Designing microservice boundaries and the contracts between them
- Event-driven workflows and asynchronous messaging
- Authentication and authorization with Keycloak / OpenID Connect
- Reporting, document generation, and query performance on large datasets
- Angular applications that stay fast and maintainable as they grow
